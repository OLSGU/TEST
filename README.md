# Реестр договоров и документов по проектам — окружение Odoo Community

Среда разработки для системы учёта договоров и документов по проектам на базе
**Odoo Community**. Этот репозиторий пока содержит **инфраструктуру** (Odoo CE +
PostgreSQL в Docker) — фундамент для пилота (Этап 0). Сам кастомный модуль
(Проект → Договор → Документ) добавляется следующим шагом.

> Архитектурное решение зафиксировано: **одна компания** (single-company).
> См. §3.2 спецификации.

## Что внутри

| Файл / каталог        | Назначение                                                        |
|-----------------------|-------------------------------------------------------------------|
| `docker-compose.yml`  | Сервисы Odoo CE и PostgreSQL с томами для данных                   |
| `config/odoo.conf`    | Конфигурация Odoo (addons_path, БД, dev-режим)                     |
| `.env.example`        | Шаблон переменных окружения (версия Odoo, порт, креды БД)          |
| `addons/project_contract_registry/` | Пилотный модуль: Проект → Договор → Документ           |
| `addons/project_contract_account/`  | Мост с бухгалтерией: договор/проект в счетах, суммы по договору |

## Требования

- Docker и Docker Compose (`docker compose version`)

## Быстрый старт

```bash
# 1. Подготовить переменные окружения
cp .env.example .env

# 2. Поднять Odoo + PostgreSQL
docker compose up -d

# 3. Дождаться запуска и открыть в браузере
#    http://localhost:8069
```

При первом входе откроется менеджер баз данных:

1. Создайте базу (Master Password по умолчанию — `admin`, задан в
   `config/odoo.conf`, **смените перед любым внешним доступом**).
2. После входа установите локализацию **«Russia - Accounting» (`l10n_ru`)**
   через *Apps* (снимите фильтр *Apps* → найдите `l10n_ru`). Она даёт
   ИНН/КПП на контрагентах (`res.partner`).

## Полезные команды

```bash
docker compose logs -f odoo      # логи Odoo
docker compose restart odoo      # перезапуск после правок конфигурации
docker compose down              # остановить (данные сохраняются в томах)
docker compose down -v           # остановить и УДАЛИТЬ данные (чистый старт)
```

### Установка/обновление кастомного модуля

После добавления модуля в `addons/<module_name>` обновите список приложений
(*Apps → Update Apps List*) или примените миграцию из CLI:

```bash
docker compose exec odoo odoo -u <module_name> -d <database> --stop-after-init
docker compose restart odoo
```

## Версии

- **Odoo**: `19.0` (Community) — задаётся через `ODOO_VERSION` в `.env`
- **PostgreSQL**: `16`

## Пилотный модуль `project_contract_registry`

Реализует иерархию реестра **Проект → Договор → Документ** (single-company).

| Модель         | Назначение                                                          |
|----------------|---------------------------------------------------------------------|
| `pcr.project`  | Проект: заказчик, руководитель, сроки, статусы, список договоров     |
| `pcr.contract` | Договор: привязка к проекту, контрагент, тип, сумма, статусы, документы |
| `pcr.document` | Документ: привязка к договору, тип, дата, файл-вложение, статусы     |

Связи: `pcr.contract.project_id` → `pcr.project` (cascade),
`pcr.document.contract_id` → `pcr.contract` (cascade); проект и контрагент
документа наследуются от договора. Номера генерируются автопоследовательностями
(`PRJ/…`, `CTR/…`, `DOC/…`). На моделях включён чат (`mail.thread`).

Установка модуля:

```bash
docker compose exec odoo odoo -i project_contract_registry -d <database> --stop-after-init
docker compose restart odoo
```

Меню после установки: **«Реестр договоров»** → Проекты / Договоры / Документы.

## Модуль-мост `project_contract_account`

Отдельный пакет, связывающий реестр договоров с бухгалтерией
(`account`, входит в Odoo Community). Ядро реестра остаётся независимым от
учёта — мост ставится поверх.

Зависимости: `project_contract_registry`, `account`.

| Что добавляет | Где |
|---------------|-----|
| Поля **«Договор»** (`pcr_contract_id`) и **«Проект»** (`pcr_project_id`) | Счёт/счёт-фактура `account.move` |
| Проект **подтягивается** из выбранного договора (onchange) | Форма счёта |
| Договоры и проекты **фильтруются по контакту** счёта (`domain` по `partner_id`) | Форма счёта |
| Поиск/группировка по договору и проекту | Список и фильтры счетов |
| Суммы по проведённым счетам: **Выставлено / Осталось выставить / % выставлено** (возвраты вычитаются, приведение к валюте договора) | Договор `pcr.contract` |
| Смарт-кнопка «Счета» и вкладка «Счета» | Форма договора |

Связь `account.move.pcr_contract_id` → `pcr.contract` использует `ondelete='set
null'`: удаление договора не затрагивает счета, лишь обнуляет ссылку.

Установка (после базового модуля):

```bash
docker compose exec odoo odoo -i project_contract_account -d <database> --stop-after-init
docker compose restart odoo
```
